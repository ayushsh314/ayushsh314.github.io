Work

FlowMind

Multi-agent flowchart understanding

A system that answers questions about flowcharts by routing each question to the tool that can actually answer it. A TF-IDF router sends structural questions to a deterministic graph traversal and language questions to an LLM examiner, with a Qwen3-VL-2B vision reader recovering graph structure from images.

The router hits roughly 99.5% accuracy, and structural question answering reaches 98.7%.

That 98.7% is measured against ground-truth Mermaid source, not images. End to end from a raw image, accuracy is bounded by the vision reader's 0.860 edge F1. A self-check step on the examiner was a null result at −2.2, which I kept in the writeup as a boundary condition rather than dropping it.

Built with Purvaja Narayana and Shrijan Shetty. I owned measurement, the LLM stack, vision experiments, and results documentation.

MarketSensAI

Multi-agent financial analysis, MS capstone

Four agents arranged as a linear LangGraph state machine, moving a company from raw filings and news through to a structured analysis. A FAISS index over MiniLM-L6-v2 embeddings handles follow-up questions against the same corpus.

Evaluated four ways, including an LLM-as-judge pass over the serialized milestone JSON each agent emits.

The judge reads the serialized milestones, not the source articles, so it scores internal consistency rather than factual grounding. The generator is Qwen2.5-3B-Instruct, small enough that reasoning quality is the binding constraint on output, not retrieval.

Research Buddy

Graph-based literature assistant

A research assistant built on LlamaIndex PropertyGraphIndex, using Neo4j purely as a property graph store. Hierarchical Leiden clustering via graspologic groups the extracted entities into communities, each summarized to support questions that span many papers rather than sitting inside one.

Runs fully local on GIST-all-MiniLM-L6-v2 embeddings and Qwen2.5 through Ollama.

Community summaries live in memory and are lost between runs. The corpus is titles and abstracts only, so the system reasons about what papers claim, not about what their methods sections say.

Physics-informed neural networks

Undergraduate research, with IIT Kanpur

Work on PINNs for solving differential equations, focused on making training tractable on GPU rather than on new architectures.

Reached a 28.2x speedup over the baseline implementation.

The speedup is an implementation and hardware result. It does not change solution accuracy or the class of equations the method handles.

Part of a body of undergraduate research that produced five IEEE publications.
