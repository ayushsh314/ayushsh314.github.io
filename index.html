Projects

FlowMind

Multi-agent flowchart understanding

A system that answers questions about flowcharts by routing each question to the tool that can actually answer it. A TF-IDF router sends structural questions to a deterministic graph traversal and language questions to an LLM examiner, with a Qwen3-VL-2B vision reader recovering graph structure from images.

The router hits roughly 99.5% accuracy, and structural question answering reaches 98.7%.

Repository

MarketSensAI

Multi-agent financial analysis, MS capstone

Four agents arranged as a linear LangGraph state machine, moving a company from raw filings and news through to a structured analysis. A FAISS index over MiniLM-L6-v2 embeddings handles follow-up questions against the same corpus.

Evaluated four ways, including an LLM-as-judge pass over the serialized milestone JSON each agent emits.

Research Buddy

Graph-based literature assistant

A research assistant built on LlamaIndex PropertyGraphIndex, using Neo4j purely as a property graph store. Hierarchical Leiden clustering via graspologic groups the extracted entities into communities, each summarized to support questions that span many papers rather than sitting inside one.

Runs fully local on GIST-all-MiniLM-L6-v2 embeddings and Qwen2.5 through Ollama.
